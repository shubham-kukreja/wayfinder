# Data Sources — Tracker

Tracks every externally-fetched data point the allocation framework needs (per the multi-asset spec's Category 3), its adapter, and how close it is to a real automatic feed. Update this file whenever an adapter's status changes — this is the source of truth for "is X actually live," not memory or a chat summary.

Status legend:
- ✅ **Live** — adapter fetches this exactly as spec'd, verified against a live response.
- ⚠️ **Proxy/Partial** — adapter returns *something* real, but not an exact match to the spec'd instrument, or covers only part of what's needed.
- ❌ **Missing** — no adapter exists; value is manual-input only today.

Series IDs are the internal keys used in `packages/engine`'s `Scores`/`Snapshot` types (`${nodeId}::${signalId}` or a raw series ID feeding a rubric).
